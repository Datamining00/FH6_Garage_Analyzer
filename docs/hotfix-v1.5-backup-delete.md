# v1.5 백업 삭제 긴급 수정

- 백업 삭제 후 전체 로더를 실행하던 호출을 제거했습니다.
- 삭제된 항목은 작업 목록에서 제외하고 해당 칸만 비워 둡니다. Qt 카드 객체는 숨김·비활성 상태로 보관하고, 다른 카드의 위치·선택을 유지합니다. 전체 새로고침 때 빈칸과 보관한 객체를 정리합니다.
- 백업 개수, 게임과의 중복 관계, 메인 카드의 백업 표시와 저장소 변경 시각을 갱신합니다.
- 취소·인덱스 저장 실패 시 전체 재로딩 없이 기존 목록을 유지합니다.
- 인덱스 삭제 후 남은 파일 정리만 실패한 경우 목록에 삭제를 반영하고 경고합니다.
- 백업 목록 로딩 중이거나 확인창을 연 뒤 로딩·경로·잠금 상태가 바뀌면 삭제를 진행하지 않습니다.

이전 수정본의 삭제 후 종료 보고를 받아 즉시 객체 삭제와 카드 재배치를 제거했습니다. 사용자 환경의 정확한 충돌 경로는 재현하지 못했으므로 원인이 확정됐다고 보지는 않습니다.

잠금 썸네일 추가: 리버리 폴더의 bigThumb.webp는 캐시 연결 오류와 독립적으로 처리합니다. 미적용 경매장 항목도 폴더 안의 잠금 표시는 적용·복원하고, 해당 항목의 게임 캐시는 탐색하지 않습니다. 썸네일 쓰기 설정과 원본 보관·게임 교체 파일 보호는 유지합니다.

실제 Qt 카드 6개를 확인창을 통해 연속 삭제하고, 남은 카드 위치 유지 및 새로고침 정리를 검사합니다: source-v1.2/tools/validate_backup_delete_slots.py.
실제 게임 저장 데이터나 사용자 백업은 삭제하지 않았습니다.

2026-09-12 추가 수정 검사: 사용자 설정을 분리한 임시 LOCALAPPDATA에서 전체 자동 검사 1,111개 통과. 백업 빈칸 유지 및 새로고침 정리, 캐시 연결 오류 시 폴더 잠금 쓰기, 미적용 경매장 폴더 잠금 적용·복원 검사를 포함합니다.
