# v1.5 백업 삭제 긴급 수정

- 백업 삭제 후 전체 로더를 실행하던 호출을 제거했습니다.
- 삭제된 항목만 화면과 메모리 목록에서 제거하고 나머지 카드 객체·선택을 유지합니다. 전체 카드를 숨겼다가 다시 보여주지 않고 빈자리만 정리합니다.
- 백업 개수, 게임과의 중복 관계, 메인 카드의 백업 표시와 저장소 변경 시각을 갱신합니다.
- 취소·인덱스 저장 실패 시 전체 재로딩 없이 기존 목록을 유지합니다.
- 인덱스 삭제 후 남은 파일 정리만 실패한 경우 목록에 삭제를 반영하고 경고합니다.
- 백업 목록 로딩 중이거나 확인창을 연 뒤 로딩·경로·잠금 상태가 바뀌면 삭제를 진행하지 않습니다.

검증: Python 3.12.14, 임시 저장소 기반 전체 검사 1,107개 통과(신규 10개 포함).
실제 게임 저장 데이터나 사용자 백업은 삭제하지 않았습니다.
