# v1.5 중복 백업 옵션 수정

이전 구현은 '이름이 같은 리버리 중복 백업 허용'을 켜면 이름이 다른 동일 해시 항목도 허용했습니다. 이제 두 옵션을 독립적으로 적용합니다.

- 종류·내용 해시가 다른 항목은 이름에 관계없이 별개로 저장합니다.
- 같은 종류·해시의 기존 백업에 같은 이름이 있으면 '같은 이름 허용'을 적용합니다.
- 같은 종류·해시의 기존 백업에 다른 이름만 있으면 '다른 이름 허용'을 적용합니다.
- 같은 이름과 다른 이름이 모두 있으면 같은 이름 규칙이 우선합니다.
- 현재 일괄 작업에서 저장한 항목도 즉시 중복 판정에 포함합니다.
- 자동 백업은 기존 항목을 반복 저장하지 않는 추가 보호를 유지합니다.
- 이름 비교의 기존 앞뒤 공백 제거 및 대소문자 구분 방식을 유지합니다.
- 기존 백업 파일, 대상 선택, 복사·잘라내기 보호 및 숨김 이동 수정은 유지합니다.

수동·선택·일괄 백업과 자동 백업 및 외부 자료 가져오기는 공통 안전 백업 함수를 사용합니다.

검증: 임시 데이터로 전체 자동 검사 1,120개 통과. 신규 6개 검사는 기존 백업/동일 배치의 16개 조합 각각, 혼합 이름 우선순위 8개 조합, 자동 백업 8개 조합과 반복 저장 방지 등을 포함합니다. 실제 게임 데이터와 사용자 백업은 변경하지 않았습니다.
