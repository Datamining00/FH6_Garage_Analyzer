# FH6 Assistant v1.5 라이선스 보완 결과

2026-09-12. 산출물: artifacts/v1.5-license-compliance. 기존 배포본과 바탕화면 파일은 보존했다.

## 완료한 기술 보완

- 일반판·포터블에서 Qt6VirtualKeyboard.dll 및 qtvirtualkeyboardplugin.dll을 제외했다. PySide6/Qt 핵심 기능은 유지했다.
- 설정창 하단에 오픈소스 및 라이선스 열람 버튼을 추가했다. 인터넷 연결 없이 원문을 볼 수 있다.
- KFPS·ForzaTechStudio·.NET·Python 및 주요 라이브러리 고지를 넣었다. 두 실행 형태와 소스 ZIP에 동일한 고지·안내 파일 2533개가 들어 있는지 바이트 단위로 비교했다. Qt 원본의 선택적 구성요소·예제 고지도 보존했으므로 이 개수가 실행 중인 라이브러리 개수라는 뜻은 아니다.
- KFPS 렌더러 신규 설치 시 라이선스를 보존하고, 기존 설치도 첫 렌더러 준비 때 번들 원문으로 보완한다. 렌더 데이터·캐시를 재생성하지 않는다. 임시 파일 검사에서 원자적 교체 실패 시 기존 고지를 보존하고 임시 파일을 정리했다.
- Qt/PySide6 6.11.2 공식 소스 7개를 공식 SHA-256과 비교해 소스 ZIP에 포함했다. PyOpenGL 3.1.10 소스 및 KFPS 변환기 고정 커밋의 원본 66개 파일도 포함했다. KFPS 원본은 Git blob 해시로 확인했다.
- LGPL 라이브러리 소스 제공, 교체·재구성·디버깅 안내를 추가했다. 앱 전체를 임의로 GPL/AGPL/MIT로 변경하지 않았다.

## 실제 검증

- Python 3.12.14에서 소스 ZIP을 추출해 자동 검사 1097개 통과.
- 소스 ZIP에서 일반판과 포터블을 각각 재빌드하고 실행·종료 확인.
- 배포 일반판, 실제 ZIP을 푼 포터블, 소스 직접 실행, 재빌드한 두 실행 파일 모두 격리 시작·종료 통과.
- 앱 모듈 190개와 진입점이 배포 실행 파일 및 소스와 일치.
- 라이선스 열람 UI, 일반 키 이벤트, 한글 입력 확정(QInputMethodEvent) 확인. 실제 Windows IME의 조합 키를 사람이 누르는 수동 검사는 하지 않았다.
- 설정창 100·150·200%: 글자 너비·가로 넘침 검사 통과, 행 간격 최소 6px, CPU 자동/증감 조작 유지. 100% 이미지를 직접 확인했다.
- 임시 튜닝 412개 카드·표 표시, 이동 감시·다운로드 이후 새로고침, 썸네일 쓰기/복원, 미리보기 중앙 배치, 작업 완료 후 종료 검사 통과.
- 실제 게임 키 입력, 사용자 저장소·썸네일 쓰기 테스트는 수행하지 않았다. 외부 라이브러리 전체를 소스부터 재컴파일하거나 새 PC의 모든 환경을 검증한 것은 아니다.

## 데이터·허가에 관한 남은 범위

- 사용자 제공 화면에서 HDR이 프로젝트 사용 사실에 긍정적으로 답한 것을 확인했다. 이전의 단순 '허가 응답 미확인' 기록을 보완했다. 다만 표현에 없는 모든 재배포 형태까지 확대 해석하지 않는다.
- Hydra 데이터의 별도 허가 답변은 확인되지 않았다. 게임 유래 SQLite 데이터의 권리 범위는 코드 라이선스와 구분한다.
- Doliman 수식/구조 참고와 코드 표현 복제는 구분해야 한다. 이 조사만으로 앱 전체의 GPL/AGPL 의무를 확정하지 않는다.
- 해당 기능은 삭제하거나 정확도를 낮추지 않았다. 고지 추가만으로 데이터 권리가 새로 생기는 것도 아니다.

따라서 이 파일은 **기술 보완과 검사 완료본**이며, **모든 데이터 권리를 확인한 공개 배포 최종 승인본**으로 표시하지 않는다. source-v1.2/DATA_PROVENANCE_REVIEW.md에 출처와 확인 범위를 기록했다.

## 배포 방식과 제한

소스 ZIP은 공식 라이브러리 소스를 함께 담아 약 700MB다. 바이너리 배포 시 같은 페이지에서 소스 ZIP도 제공하고, THIRD_PARTY_NOTICES.md 및 SOURCE_AND_RELINKING.md 안내를 유지한다. 압축은 C:\FH6처럼 짧은 경로에 푼다.

기존 3D 창 최소 너비 924px 제약과 차량별 게임 썸네일 각도와의 정확한 일치 미검증은 그대로다. 공개 고지·감사 자료는 동작 또는 법적 권리 전부의 보증을 의미하지 않는다.

근거: validation/license-package-checks.json, archive-checks.json, source-checks.json, source-build.json, launches.json 및 개별 로그. SHA256SUMS.txt는 현재 세 산출물의 해시다.
