# 카드 선택 내보내기 및 백업 보호 — 2026-09-11

## 동작

- 상단 버튼은 기존 `내보내기` 이름과 배치를 유지한다.
- 리버리 탭은 현재 검색·필터에 해당하는 게임 리버리를 백업한다.
- 백업 탭은 현재 검색·필터에 해당하는 백업을 게임의 current 및 번호 저장 위치로 복원한다.
- 스크롤 밖의 카드도 대상에 포함하고, 숨겨진/필터 제외 카드는 포함하지 않는다.
- 첫 대화상자는 `복사 / 잘라내기 / 선택 / 취소`이다. 선택하면 기존 카드 위에서 클릭하며 보라색 테두리로 선택 상태를 표시한다.
- 상단 `선택 완료`를 누르면 선택 항목만 대상으로 복사/잘라내기를 결정한다. 0개 선택은 완료할 수 없다. 취소, 탭 전환, 필터 변경으로 카드가 숨겨지거나 재생성되면 선택을 해제한다.
- 잠긴 항목은 복사할 수 있으나 잘라내기 시 원본을 유지한다. 전부 잠긴 목록 및 잘라내기 비활성화 설정에서는 잘라내기 버튼을 비활성화한다.
- 개별 백업 복원도 원본 삭제 전에 잠금을 다시 검사한다. 백엔드 복원 함수도 잘라내기 비활성화 설정을 검사한다.
- 경매장 카드와 백업 카드에 기존 아이콘/위치의 잠금 버튼을 제공한다. 백업 잠금은 저장 경로별로 구분하며 동일 내용의 다른 항목으로 전파하지 않는다.
- 다운로드 표시는 기존 위치에서 `다운로드:YYYY-MM-DD`로 표시하며 날짜 표시 옵션을 따른다.

## 안정성

- 저장소 읽기 → 파일 검증 및 게시/삭제 → 목록 저장을 앱 내부 공용 재진입 잠금으로 직렬화한다. 자동·수동·외부 백업 및 복원/삭제 간 목록 덮어쓰기를 방지한다.
- 자동 처리기는 외부 가져오기, 확인 대화상자, 카드 선택 도중 시작하지 않는다. 확인 대화상자 이후 작업 상태를 재검사한다.
- 자동 인식은 `C_livery`와 `header`의 크기·수정 시간을 함께 검사한다.
- 복원 대상에 다른 데이터가 있으면 덮어쓰지 않고 해당 항목을 실패로 보고한다. 해당 백업 원본은 유지한다.
- 백업·이동 작업 중 창 종료를 차단하여 작업 스레드가 도중에 파괴되지 않게 한다.

## 검증

- 전체 테스트 1,009개 통과.
- 동시 백업/삭제 목록 보존, 동일 내용 항목 잠금 분리, 백업 잠금 키 재연결, 헤더만 변경 감지, 외부 가져오기 도중 자동 백업 억제 검증.
- 카드 선택/테두리/취소/필터 변경, 선택 항목만 전달, 양방향 목록 범위, 잘라내기 비활성화 및 잠금 원본 보존 검증.
- 실제 앱 카드 생성 코드로 경매장 잠금·다운로드 문구·카드 테두리와 선택 도구 모음 확인.
- 파일 복사/삭제 테스트는 임시 저장소와 임시 게임 저장 구조만 사용. 실제 게임 저장 데이터는 수정하지 않았다.
- 저장소 잠금은 단일 앱 프로세스 내 작업을 보호한다. 서로 다른 앱 인스턴스 간 동시 수정은 이번 범위에 포함하지 않는다.
