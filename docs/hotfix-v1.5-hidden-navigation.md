# v1.5 숨김 리버리 이동 위치 수정

FHA에서 리버리를 숨기면 게임에는 그대로 남는데도 수동 새로고침의 이동 목록에서 제외되어, 다른 항목의 행·열과 순환 이동 거리가 달라졌습니다.

- 숨김 항목도 게임 이동 위치 계산에 포함합니다.
- 숨김 화면 표시와 숨긴 항목 자체의 이동 제한은 유지합니다.
- 수동 새로고침과 자동 감지의 이동 목록 구성을 일치시킵니다.
- 신규 추가 감지 시 이동 전 새로고침과 실제 삭제 확인 항목 제외는 유지합니다.

회귀 검사에는 홀수·짝수 목록의 모든 숨김 위치, 여러 항목 숨김, 수동·자동 목록 및 경로 비교, 실제 삭제 항목 제외를 포함합니다. 합성 데이터를 사용하며 게임 방향키 입력과 사용자 저장 데이터 변경은 수행하지 않습니다.

2026-09-12: 임시 사용자 설정으로 전체 자동 검사 1,114개 통과. 게임 내 실제 도착 위치 확인은 별도 사용자 확인이 필요합니다.
