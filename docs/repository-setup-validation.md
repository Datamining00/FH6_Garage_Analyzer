# v1.5 저장소 구성 검증

2026-09-12, `release/v1.5-repository` 작업 폴더에서 수행했습니다.

- 기준: 기존 작업 폴더의 `work/license-compliance/source-v1.2`.
- 앱 Python 파일 213개와 `app.py`는 기준과 바이트 단위로 일치합니다. 기능 코드는 이번 정리에서 변경하지 않았습니다.
- 기존 미커밋 작업과 배포 파일은 원래 작업 폴더에 보존했습니다.
- Python 3.12.14에서 격리 회귀 검사 1,097개 통과. 초기에는 이동된 workflow 경로를 참조하던 검사 3개가 실패했고, 현재 구조에 맞춘 뒤 전체를 다시 실행했습니다.
- 새 빌드 명령으로 일반판·포터블 빌드 성공. 두 실행 파일은 임시 설정과 offscreen 환경에서 실행·자동 종료 모두 종료 코드 0을 반환했습니다.
- 실행부터 자동 종료까지 일반판 6.436초, 포터블 2.690초. 이 값은 1.5초 종료 대기를 포함하며 시작 속도 비교 측정이 아닙니다.
- 외부 소스 9개 아카이브 검증 통과. 기존 파일의 SHA-256 및 KFPS 파일별 Git blob 해시를 검사했습니다. 새 네트워크 다운로드 경로는 이번 실행에서 검증하지 않았습니다.
- 새 패키징 명령으로 일반판 EXE·포터블 ZIP·전체 소스 ZIP 생성 성공. ZIP CRC, 포함 앱 코드와 현재 소스 일치, 포터블 외부 고지 일치, Qt 가상 키보드 제외를 확인했습니다.
- Git 대상에 100MiB 이상 파일과 외부 소스 대형 아카이브가 포함되지 않음을 확인했습니다.
- GitHub Actions 원격 실행·GitHub 게시·실제 게임 데이터 변경 검사는 수행하지 않았습니다.

이전 배포 검증 기록은 [v1.5-validation.md](v1.5-validation.md), 남은 기능·이용 조건 확인 사항은 [KNOWN_ISSUES.md](../KNOWN_ISSUES.md)에 있습니다.
