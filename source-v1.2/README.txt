FH6 Assistant v1.3.3 Beta
================================

실행 방법
---------
1. 이 압축 파일을 쓰기 가능한 일반 폴더에 완전히 풉니다.
2. FH6 Assistant.vbs를 실행합니다.
3. 최초 실행에서는 Python 환경과 필수 패키지 준비로 시간이 걸릴 수 있습니다.

오류 확인
---------
- 프로그램이 열리지 않으면 run.bat을 실행하십시오.
- run.bat은 오류 내용을 CMD 창과 로그로 확인하기 위한 진단용 실행 파일입니다.
- 정상 사용 시에는 FH6 Assistant.vbs만 실행하면 됩니다.

주의 사항
---------
- 압축 파일 내부에서 직접 실행하지 마십시오.
- app.py, run.bat, setup_and_run.ps1, requirements.txt, data 및 fh6garage 폴더를
  서로 분리하거나 삭제하지 마십시오.
- FH6 세이브와 CacheThumbnails는 읽기 전용으로 처리됩니다. 프로그램이 직접
  게임 세이브/캐시 파일을 생성·수정·삭제하지 않습니다.
- 메모리 스캔은 OpenProcess의 읽기/조회 권한과 VirtualQueryEx,
  ReadProcessMemory만 사용합니다. 메모리 쓰기, 코드 주입, 후킹, 디버거 연결은
  사용하지 않습니다.
- 설정·분류·분석 캐시·최근 변경 썸네일 복사본·마지막 메모리 스캔 결과는
  %LOCALAPPDATA%\FH6GarageAnalyzer 아래에 저장됩니다.
- 스캔 캐시는 최근 저장 경로 최대 5개, 마지막 사용 후 최대 30일 기준으로
  자동 정리됩니다. 중단된 쓰기의 임시 파일은 24시간 후 자동 정리됩니다.
- 썸네일 메모리 캐시는 PC 메모리에 맞춘 LRU 상한을 사용하고 프로그램 종료 시
  해제됩니다. 새로고침 기록의 디스크 썸네일은 현재 목록과 최근 변경에 필요한
  파일만 유지합니다.
- 인게임 이동 기능은 Windows 키 입력을 FH6 창으로 전달합니다. 이는 게임 파일이나
  프로세스 메모리를 직접 수정하는 방식이 아닙니다.

메모리 구현 참고
---------------
현재 메모리 스캔 구현은 공개된 Win32 API와 관찰된 FH6 런타임 레코드 형식을
기반으로 별도로 작성되었습니다. 공개 커뮤니티 연구인 Hx-zh/fh6-livery-viewer
(AGPL-3.0)의 기능적 관찰 결과와 교차 확인했지만 해당 프로젝트의 소스 코드를
포함·임포트·링크하지 않습니다.
