# 데이터·참고 구현의 확인 범위

2026-09-12. 기능을 임의로 제거하지 않고 기존 데이터 사용 경로를 유지했다. 아래 미확인 사항은 고지 추가만으로 해결됐다고 표시하지 않는다.

| 자료 | 실제 사용 | 확인한 원문 조건 | 남은 사항 |
|---|---|---|---|
| HDR 차량 ID Gist | car_names.json에 포함, 원본 URL 기록 | Gist 파일/설명에서 명시적 라이선스를 찾지 못함 | 사실 정보와 편집물의 구분, 데이터 묶음 사용·재배포 허용 범위 |
| HDR 튜닝 구조 | 바이너리 필드 구조 참고 | Gist 파일/설명에 명시적 라이선스 없음 | 문서 표현 복제와 형식 참고 구분 |
| Hydra 25cfd00 SQLite | 휠 기본 사양용 DB를 필요 시 다운로드, 파일 해시 검증 | host/QING.Core AGPL-3.0-only. README는 더 이전 출처 fh6-file-analyse 언급 | DB 자체·게임 유래 데이터의 권리 조건. 다운로드 경로라는 이유로 권리 문제를 면제하지 않음 |
| Hydra FH6TuneDatabase.cs | tire_morph_semantic_evidence.py에서 구조 참고 출처 표시 | QING.Core AGPL-3.0-only | 현재 C# 라이브러리 링크/전체 코드 포함은 찾지 못함. 완전한 코드 표현 복제 감사는 아님 |
| Doliman d126767 | rim_morph_weights 및 진단용 tire_morph_weights의 수식 | 원본 GPL-3.0 | 원본 carbin_importer.py의 2107·2154행과 공식 대응. 수식·수치 관계 참고만으로 앱 전체 GPL 여부를 단정하지 않음 |
| 게임/보충 차량 데이터·이미지/아이콘 | 기존 기능과 포함 자료 유지 | 자료별 원출처 확인 필요 | 오픈소스 코드의 라이선스가 게임 자산 재배포 권리까지 부여하지 않음 |

사용자는 해당 공개 저장소에 프로젝트에서 사용했다는 사실을 고지했다고 설명했다. 고지 원문 URL 및 상대방의 허가 답변은 제공되지 않아 독립적으로 확인하지 못했다. 사용 고지 완료(사용자 설명), 허가 여부 미확인으로 기록한다. 권리자의 추가 허가를 받은 것으로 표시하거나 사용자 명의로 연락하지 않았다. 이 문서로 미확인 권리가 해결되지 않으며, 공개 배포 최종 승인은 여전히 남은 권리 확인을 전제로 한다. GPL/AGPL 전체 적용이나 데이터 제거는 임의로 수행하지 않았다.

사용자 제공 화면 추가 확인: HDR은 사용자의 프로젝트 감사 댓글에 차량 자료와 튜닝 구조가 도움이 되었다니 기쁘다는 취지로 긍정적으로 답변했다. HDR의 사용 인지·긍정 응답은 확인하였으며, 이를 모든 형태의 재배포를 명시적으로 허가한 문구로 확대하지 않는다. Hydra에 대한 동의 답변으로도 간주하지 않는다.
