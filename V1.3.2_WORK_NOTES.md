# FH6 Assistant v1.3.2 work notes

- Base: `v1.3.1-work`
- Adds `SoulBoundLivery` / auction-livery visibility without adding those records to the in-game My Designs navigation session.
- Adds independent `My Designs liveries` and `Auction liveries` display toggles.
- Adds a selectable/auto-detected `CacheThumbnails` path.
- Parses only the verified first table of `.manifest` (v2) to resolve GUID-named WebP files.
- Uses embedded SoulBound container timestamps for auction download ordering; Windows file CreationTime is not used for sorting.
- Thumbnail matching uses acquisition-time proximity on normal installs and manifest insertion-order fallback when cache file creation times collapse (for example after a reinstall/copy).

Important: the 26-character token in the manifest logical name is **not** currently treated as a derivation of the SoulBound header GUID. The previously suspected direct Crockford-Base32 relationship did not survive binary re-verification and is intentionally not implemented.
