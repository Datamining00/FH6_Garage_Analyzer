# FH6 Assistant

FH6의 로컬 저장 데이터와 썸네일 캐시를 분석하여 저장된 리버리, 튜닝, 차량 및 제작자 정보를 확인하고 관리할 수 있는 Windows용 데스크톱 프로그램입니다.

리버리와 튜닝이 많아졌을 때 게임 안에서 하나씩 확인해야 하는 불편을 줄이고, 저장된 콘텐츠를 검색·정렬·분류하거나 원하는 리버리의 게임 내 위치까지 이동하는 작업을 보조하는 것을 목적으로 합니다.

현재 프로그램은 **단일 Windows 실행 파일(.exe)** 형태로 배포되며 Python이나 별도의 패키지 설치가 필요하지 않습니다.

> [!CAUTION]
> 이 프로젝트는 비공식 커뮤니티 도구이며 Microsoft, Xbox, Turn 10 Studios, Playground Games 또는 Forza와 제휴 관계가 없으며 해당 기관의 보증을 받지 않았습니다.
>
> FH6의 로컬 파일 구조를 분석하여 동작하므로 게임 업데이트, 플랫폼, 사용자 환경 또는 캐시 상태에 따라 일부 기능의 동작이 달라질 수 있습니다.
>
> 캐시 폴더를 직접 관리하는 경우 삭제보다는 이름 변경 등을 이용해 기존 데이터를 백업하는 것을 권장합니다.

## 주요 기능

### 리버리 관리

* 저장된 리버리의 차량명, 리버리명, 제작자 정보 확인
* 리버리 설명 등 파일에 기록된 상세 정보 확인
* 차량명, 리버리명, 제작자 기준 검색
* 차량, 제작자 및 저장 시점 등을 기준으로 정렬
* 동일 차량 리버리 그룹 표시
* 동일한 `C_livery` 데이터를 기준으로 중복 리버리 판정
* 썸네일 확대
* 사용자 메모
* 원 / 삼각형 / X 상태 분류
* 리버리 숨김 및 숨김 목록 관리
* 여러 상태 조건을 조합한 필터링
* 차량명, 리버리명, 제작자명을 클릭하여 클립보드 복사

분류, 메모 및 숨김 정보는 FH6 세이브 파일이 아닌 FH6 Assistant의 로컬 설정에 저장됩니다.

### 경매장 리버리

경매장에서 구매한 차량에 포함된 `SoulBoundLivery`를 일반적인 내 디자인 리버리와 별도로 확인할 수 있습니다.

경매장 리버리 분석에는 다음 정보가 사용됩니다.

* FH6 세이브 데이터의 `SoulBoundLivery`
* `CacheThumbnails`
* CacheThumbnails의 `.manifest`
* 리버리 식별 정보
* 썸네일 GUID 매핑 정보

프로그램에서는 다음 두 리버리 표시 모드를 사용할 수 있습니다.

* **내 디자인 리버리**
* **경매장 리버리**

두 모드는 별도로 표시됩니다.

경매장 리버리의 적용 상태와 캐시 등록 상태를 분석할 수 있으며, `.manifest`에 썸네일 GUID 매핑이 존재하는 경우 해당 WebP 썸네일을 연결하여 표시합니다.

> [!IMPORTANT]
> 경매장 리버리 기능을 처음 사용하는 경우 기존 `CacheThumbnails` 폴더를 바로 삭제하기보다는 이름을 변경하여 백업한 뒤 FH6를 실행하는 것을 권장합니다.
>
> 이후 **리버리가 적용된 경매장 구매 차량에 한 번 탑승**하고 FH6 Assistant에서 `전체 새로고침`을 실행해 주세요.
>
> Xbox App / Microsoft Store와 Steam은 `CacheThumbnails` 경로가 다를 수 있으므로 프로그램에 지정된 캐시 경로가 실제 FH6에서 사용하는 위치와 일치하는지 확인해야 합니다.

### 경매장 리버리의 현재 제한 사항

경매장 차량의 `SoulBoundLivery`는 차량 및 리버리 자체를 식별할 수 있지만, 리버리 제목과 제작자명을 저장하는 FH6 내부 데이터 구조와 연결 관계는 아직 완전히 분석되지 않았습니다.

따라서 현재 Beta 버전에서는 다음 정보가 실제 값이 아닌 기본값으로 표시될 수 있습니다.

* 리버리 제목
* 제작자명

이는 해당 정보가 FH6에 존재하지 않는다는 의미가 아니라, 현재 FH6 Assistant에서 안정적으로 추출할 수 있는 데이터 구조가 확인되지 않았다는 의미입니다.

또한 실제 WebP 썸네일 파일이 캐시에 존재하더라도 `.manifest`에 logical name과 GUID 사이의 매핑이 기록되지 않은 상태에서는 경매장 리버리 썸네일이 `No thumbnail`로 표시될 수 있습니다.

## 튜닝 정보

저장된 튜닝 파일을 분석하여 다음 정보를 읽기 전용으로 확인할 수 있습니다.

* 적용 차량
* 튜닝 제작자
* 장착 부품 식별 번호
* 파일에 기록된 세부 설정값

FH6 Assistant는 튜닝 파일 자체를 수정하지 않습니다.

## 차량 DB

FH6 Assistant는 차량 식별 번호(Car ID)를 차량 정보와 연결하기 위한 별도의 차량 DB를 사용합니다.

### 사용자 차량 이름

DB에 아직 등록되지 않은 차량이나 사용자가 직접 이름을 지정하고 싶은 Car ID에 사용자 정의 차량명을 설정할 수 있습니다.

FH6 업데이트 직후처럼 차량 DB가 최신 상태가 아닌 경우에도 직접 차량명을 지정하여 사용할 수 있습니다.

### DB 업데이트 확인

프로그램에서 사용하는 차량 DB의 최신 버전을 확인할 수 있습니다.

### DB 원본 자료

차량 ID 데이터의 원본 자료를 브라우저에서 확인할 수 있습니다.

원본 데이터 자체에 일부 차량의 연도 또는 기타 정보가 정확하지 않은 경우가 있을 수 있습니다.
