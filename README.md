# FH6 Assistant

FH6의 로컬 저장 데이터와 썸네일 캐시를 분석하여 **리버리·튜닝·차량 정보를 확인하고 관리하는 Windows용 프로그램**입니다.

[다운로드 및 변경 사항](https://github.com/Datamining00/FH6_Garage_Analyzer/releases)

> [!IMPORTANT]
> 비공식 커뮤니티 도구입니다. 게임 업데이트에 따라 일부 기능이 달라질 수 있습니다. **복원·잘라내기·썸네일 쓰기는 파일을 변경하므로 사용 전 백업을 확인해 주세요.**

## 설치 및 실행

1. 일반판 실행 파일 또는 포터블 ZIP을 내려받습니다.
2. 포터블은 압축을 모두 풀고 내부 실행 파일을 실행합니다.
3. `세이브 폴더 선택`과 `캐시 경로 선택`에서 실제 FH6 폴더를 지정합니다.
4. `전체 새로고침`을 실행합니다.

| 배포 파일 | 용도 |
|---|---|
| 일반판 EXE | 단일 실행 파일 |
| 포터블 ZIP | 실행 파일과 구성 파일 |
| 전체 소스 ZIP | 앱 소스·빌드 자료·외부 라이브러리 소스 |

Python을 별도로 설치할 필요는 없습니다. 일부 미리보기 도구와 데이터는 첫 사용 시 다운로드됩니다. 포터블은 `C:\FH6`처럼 짧은 경로에 풀어 주세요.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 대시보드 | 차량·리버리·튜닝 및 적용 상태 집계 |
| 리버리 관리 | 일반·경매장 리버리 카드, 상세 정보, 이름 복사 |
| 검색·정렬·그룹화 | 차량·제작자·제목·설명·메모 검색, 차량·제작자별 묶기 |
| 분류·필터 | 원·삼각형·X, 메모, 중복, 숨김, 잠금, 백업·적용 상태 |
| 자동 감지 | 추가·제거·중복 카운트와 최근 변경사항 |
| 백업·복원 | 수동·자동 백업, 외부 가져오기, 복원·내보내기 |
| 썸네일 쓰기 | `Auction`·잠금 표시, 원본 보관·원복·재적용 |
| 2D·3D 미리보기 | 면별 이미지와 차량 모델, 확대·축소·화면 맞춤 |
| 메모리 스캔 | 실행 중인 FH6의 적용 상태를 읽기 전용으로 확인 |
| 게임 내 위치 이동 | 삭제·적용할 리버리까지 이동하는 키 입력 보조 |
| 차량·제작자 관리 | 차량 데이터베이스 업데이트, 사용자 차량명·제작자 이름 관리 |
| 진단·성능 | 진단 내보내기와 성능 측정 |

### 리버리 분류

메모·분류·숨김·잠금은 앱에 별도로 저장됩니다. 숨긴 항목은 `필터 → 숨김`에서 확인할 수 있습니다. 잠금은 앱의 보호 기능이며 게임 자체의 삭제를 막지는 않습니다.

중복은 `C_livery`의 실제 내용으로 판정합니다. 경매장 목록은 `SoulBoundLivery`를 대상으로 하며, 일부 제목·제작자·썸네일은 확인되지 않을 수 있습니다.

### 자동 감지와 새로고침

자동 감지는 카운트와 최근 변경사항을 갱신합니다. 메인 목록은 `전체 새로고침`으로 반영하며 검색·필터·스크롤·선택을 유지합니다.

메모리 스캔과 차량 데이터베이스 업데이트 결과를 반영한 뒤에는 필요한 목록 새로고침을 수행합니다. 메모리 스캔은 수동으로 실행합니다.

### 백업

선택한 리버리를 별도 저장소에 백업하고 복원할 수 있습니다. 자동 백업과 중복 백업 허용 조건은 설정에서 조정합니다.

**리버리 백업에는 메모·분류·숨김·원본 잠금 기록이 포함되지 않습니다.** 이 기록은 앱 사용자 데이터를 별도로 백업해 주세요.

### 썸네일 쓰기

`설정 → 썸네일에 쓰기`를 켜면 실제 썸네일에 `Auction`·잠금 표시를 넣습니다. 정확히 연결된 폴더·캐시 썸네일만 처리하며, 미적용 경매장 리버리는 새 표시에서 제외합니다.

원본과 파일명·확장자·이미지 형식을 보존합니다. 설정을 끄면 표시를 원복하며, 게임이 파일을 교체한 경우에는 덮어쓰기를 보류할 수 있습니다. 표시가 사라졌다면 `재적용`을 사용하세요.

### 미리보기

2D는 화면 확대율 100%, 3D는 공통 기본 시점의 100% 기준으로 열립니다. 렌더링 캐시, 재질 생략, 동시 작업 수를 설정할 수 있습니다. 캐시를 꺼도 기존 파일이 삭제되지는 않습니다.

3D 미리보기에는 게임 차량 자산과 OpenGL 3.3 지원 환경이 필요합니다. 차량별 시점·재질·부품 표현은 게임과 차이가 있을 수 있습니다.

### 게임 내 위치 이동

게임에서 다음 화면을 연 뒤 카드의 이동 버튼을 사용합니다.

```text
집 → 자동차 → 디자인 및 도색 → 내 디자인
```

이동은 위치 선택을 보조하며 삭제·적용 완료를 대신 처리하지 않습니다. 삭제 목적 이동 후에는 실제 삭제를 확인해 이동 계산에 반영합니다. 새 다운로드가 감지된 상태에서는 목록을 새로고침한 뒤 이동합니다.

숨긴 항목은 이동 계산에서 제외됩니다. 게임의 목록 조건과 실제 선택 위치를 확인해 주세요.

## 폴더 경로

아래는 예시이며 설치 환경에 따라 달라질 수 있습니다.

**Xbox App / Microsoft Store 저장 폴더**

```text
C:\XboxGames\GameSave\pgs\u_XXXXXXXXXXXX_XXXXXX
```

**Xbox App / Microsoft Store 썸네일 캐시**

```text
%LOCALAPPDATA%\Packages\<FH6 Package>\LocalCache\Local\LocalStorage_Cache\CacheThumbnails
```

**Steam 썸네일 캐시**

```text
%LOCALAPPDATA%\ForzaHorizon6\LocalStorage_Cache\CacheThumbnails
```

썸네일이 보이지 않으면 캐시 경로와 `.manifest`를 확인한 뒤 `전체 새로고침`을 실행해 주세요.

## 사용자 데이터

일반판과 포터블 모두 다음 위치에 사용자 데이터를 저장합니다.

```text
%LOCALAPPDATA%\FH6GarageAnalyzer
```

| 파일·폴더 | 내용 |
|---|---|
| `annotations.json` | 메모·원·삼각형·X |
| `ui_preferences.json` | 화면 설정·숨김·보호 상태 |
| `app_options.json` | 프로그램 설정 |
| `thumbnail_originals` | 썸네일 원본과 복원 정보 |
| `preview3d_runtime` | 미리보기 도구·의존성·생성 데이터 |

백업은 앱을 종료한 뒤 진행해 주세요. 썸네일 원복에 필요한 `thumbnail_originals`와 실행 도구가 포함된 `preview3d_runtime`을 임의로 삭제하지 마세요.

## 다운로드 확인

실행 파일에는 디지털 코드 서명이 없습니다. 다운로드 출처와 배포된 `SHA256SUMS.txt`의 해시를 확인해 주세요.
