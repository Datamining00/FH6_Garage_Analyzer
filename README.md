# FH6 Assistant

Forza Horizon 6의 PC 저장 데이터를 읽어 리버리와 튜닝을 찾고, 분류하고, 백업하는 Windows용 프로그램입니다.
리버리는 썸네일·2D·3D로 살펴보고, 실행 중인 게임에서 적용 상태를 확인하거나 원하는 리버리 위치로의 이동 및 기타 편의 기능을 지원합니다.

이 안내는 앱 v1.5.3, 릴리스 태그 `v1.05.03`의 전체 소스 배포본을 기준으로 작성했습니다.

지원 언어: 한국어, English

[최신 버전 다운로드](https://github.com/Datamining00/FH6_Garage_Analyzer/releases/latest)

## 다운로드

| 파일 | 용도 | 실행 방법 |
|---|---|---|
| `01-FH6.Assistant.v1.5.3.exe` | 일반 사용자용 단일 실행 파일 | 내려받은 EXE 실행 |
| `02-FH6-Assistant-v1.5.3-Portable.zip` | 실행 파일과 구성 파일을 함께 제공하는 포터블 | 압축을 모두 푼 뒤 내부 EXE 실행 |
| `03-FH6-Assistant-v1.5.3-Full-Source.zip` | 개발·소스 확인용 전체 패키지 | 압축 안의 실행·개발 안내 참고 |

일반판과 포터블에는 Python을 별도로 설치할 필요가 없습니다. 포터블은 내부 파일과 폴더를 함께 유지하세요.

변경 사항과 이전 버전은 [릴리스 페이지](https://github.com/Datamining00/FH6_Garage_Analyzer/releases)에서 확인할 수 있습니다.

## 처음 사용하기

1. 프로그램을 실행하고 한국어 또는 English를 선택합니다.
2. `설정`에서 게임 내 썸네일 표시 사용 여부를 확인합니다.
3. `세이브 폴더 선택`으로 FH6 저장 폴더를 지정합니다.
4. `캐시 경로 선택`으로 `CacheThumbnails` 폴더를 지정합니다. `자동 감지`로 찾을 수도 있습니다.
5. `전체 새로고침`을 누릅니다.
6. `대시보드`에서 읽힌 차량·리버리·튜닝 수를 확인하고, `리버리` 또는 `튜닝` 화면으로 이동합니다.

복원과 잘라내기는 게임 저장 파일이나 백업 원본을 변경할 수 있습니다.
해당 작업 전에는 게임 저장 폴더를 별도로 보관하세요.
게임 내 썸네일 표시는 실제 캐시 이미지를 변경하며, 프로그램이 원본을 따로 보관합니다.

<details>
<summary>어떤 폴더를 선택해야 하나요?</summary>

| 선택 항목 | 찾을 폴더 |
|---|---|
| 세이브 폴더 | FH6 저장 루트, `current`, 숫자로 된 버전 폴더, 또는 `ContainersRoot` |
| 캐시 경로 | `.manifest` 파일이 들어 있는 `CacheThumbnails` |
| 백업 저장 경로 | 게임 저장 폴더와 겹치지 않는 별도 폴더 |

Xbox App / Microsoft Store 저장 경로의 예:

```text
C:\XboxGames\GameSave\pgs\u_XXXXXXXXXXXX_XXXXXX
```

Xbox App / Microsoft Store 썸네일 캐시 경로의 예:

```text
%LOCALAPPDATA%\Packages\<FH6 Package>\LocalCache\Local\LocalStorage_Cache\CacheThumbnails
```

Steam 썸네일 캐시 경로의 예:

```text
%LOCALAPPDATA%\ForzaHorizon6\LocalStorage_Cache\CacheThumbnails
```

경로는 설치 위치와 계정에 따라 달라질 수 있습니다. 
백업 경로는 게임 저장 폴더 자체나 그 상위·하위 폴더로 지정할 수 없습니다.

</details>

| 특정 리버리나 튜닝 찾기 | 검색, 정렬, 차량별·제작자별 묶기 |

| 일반·경매장 리버리 구분 | 리버리 종류 및 적용 상태 필터 |
| 디자인 크게 보기 | 썸네일 확대, 부위별 2D, 차량 모델의 3D 미리보기 |

| 새로 추가되거나 제거된 리버리 확인 | 변경 자동 감지와 최근 변경사항 |
| 차량에 적용된 리버리 확인 | `메모리 스캔`과 적용 변경 내역 비교 |

| 느리거나 실패하는 작업 확인 | `성능 측정`, `진단 내보내기` |
| 차고 전시 차량, 다른 차량의 리버리 해상도 개선 | 설정의 해상도 변경 |

### 대시보드에서 전체 현황 보기

- 읽힌 차량·리버리·튜닝 수와 적용 상태 집계를 확인합니다.
- `차량별` 또는 `제작자별`로 목록을 보고 검색·정렬할 수 있습니다.
- 목록의 차량이나 제작자를 선택하면 해당 리버리·튜닝을 확인할 수 있습니다.
- 차량 데이터베이스를 업데이트하거나, 표시할 차량명을 직접 지정할 수 있습니다.
- Datamining00 차량 데이터를 사용할 때는 제공되는 획득처·DLC 정보도 확인할 수 있습니다.

### 리버리와 튜닝 찾고 정리하기

검색창에서 차량명·제작자·제목·설명·메모를 찾습니다.
제조사·제작자·다운로드 순서로 정렬하고, 차량별 또는 제작자별로 묶을 수 있습니다.

| 기능 | 사용 방법 |
|---|---|
| ○·△·× 분류 | 카드에서 표시를 켜고 `필터`로 원하는 분류만 보기 |
| 메모 | 메모 버튼으로 작성·수정. 같은 제작자의 리버리에는 메모 일괄 추가·삭제 가능 |
| 중복 확인 | `중복 리버리` 필터로 실제 내용이 같은 항목 확인 |
| 숨김 | 카드의 숨김 버튼 사용. 숨긴 항목은 숨김 필터로 다시 확인 |
| 리버리 잠금 | Assistant의 인게임 이동·잘라내기·백업 삭제 제한 |
| 튜닝 잠금 | 해당 튜닝의 메모·분류 편집 제한 |
| 이름 복사 | 카드의 차량명·제작자명·제목을 클릭하여 복사 |
| 상세 정보 | 정보 버튼으로 설명·업로드 날짜 등을 확인 |
| 폴더 열기 | 카드의 폴더 버튼으로 원본 위치 확인 |

○·△·×의 용도는 사용자가 정할 수 있습니다.
숨김 버튼이 보이지 않으면 `설정 → 숨김 버튼 활성화`를 확인하세요.
잠금은 Assistant 안의 보호 기능이며, 게임에서 직접 수행하는 삭제를 막지는 않습니다.

일반 리버리와 경매장 리버리를 나누어 볼 수 있고, 적용된 항목·미적용 항목·백업 유무 등으로 표시 대상을 좁힐 수 있습니다.
경매장 리버리는 제목·제작자·썸네일 정보가 일부 확인되지 않을 수 있습니다.

튜닝의 상세 창에서는 장착 부품 식별값과 기어비·공기압·얼라인먼트·스프링·댐핑·브레이크·디퍼렌셜 등의 값을 조회하나 현재 완전한 기능은 아닙니다.
표시값은 파일에서 읽은 값이며, 게임 화면의 단위와 다를 수 있습니다.
튜닝 화면에서는 메모·분류·숨김·편집 잠금·썸네일 확대·폴더 열기를 지원합니다.
백업·복원과 인게임 이동은 리버리를 대상으로 합니다.

### 썸네일·2D·3D 미리보기

리버리 카드의 돋보기 버튼을 누르고 원하는 탭을 선택합니다.

| 탭 | 확인할 내용 | 조작 |
|---|---|---|
| 썸네일 | 저장되어 있는 이미지 | 휠로 확대·축소, 드래그로 이동, `100%`·`맞춤` |
| 2D | 앞·뒤·위·좌우·스포일러·유리 등 리버리 부위 | 부위 선택, `1x / 2x / 4x` 배율로 렌더링, 확대·축소, 화면에 맞춤 |
| 3D | 차량 모델 위에 표시한 리버리 | 왼쪽 드래그로 회전, 오른쪽 드래그 또는 Shift+왼쪽 드래그로 이동, 휠로 확대·축소 |

2D와 3D는 해당 탭을 선택할 때 준비합니다.
첫 사용 시 필요한 도구나 데이터 준비에 시간이 걸릴 수 있습니다.
3D에는 읽을 수 있는 FH6 차량 자산과 OpenGL 3.3 지원 환경이 필요합니다.
차량별 시점·재질·부품 표현은 게임 화면과 차이가 있을 수 있습니다.
현재 오류가 많은 기능으로 개선 작업 중에 있습니다.

<details>
<summary>3D 미리보기의 세부 옵션</summary>

| 옵션 | 용도 |
|---|---|
| 배율 `1x / 2x / 4x / 8x / 16x` | 리버리 렌더링 해상도 선택. 높은 배율은 메모리와 처리 시간이 더 필요 |
| 표면 선택 `Legacy / Strict / Declared + confirmed` | 리버리를 표시할 차량 표면을 선택하는 방식 |
| `UV0 / UV1 / UV2 / UV3` | 리버리 이미지와 차량 표면을 연결할 좌표 채널 선택 |
| `A` | 휠·겹친 표면 등 기본 정리 |
| `B` | 대체 표면 추가 정리 |
| `3D 미리보기 생성` | 선택한 옵션으로 생성·다시 렌더링 |
| `카메라 초기화` | 기본 시점으로 돌아가기 |

</details>

### 리버리 백업·복원·내보내기

세 작업은 저장하는 위치와 목적이 다릅니다.

| 작업 | 목적 |
|---|---|
| 백업 | Assistant의 백업 저장소에 보관하고 목록·복원 정보 함께 관리 |
| 복원 | 백업 저장소의 리버리를 게임 저장 구조에 복사 |
| 내보내기 | 선택한 별도 폴더에 리버리 원본 폴더 복사 |

백업하기:

1. `백업` 화면에서 저장 경로를 확인합니다. 별도 지정이 없으면 앱 사용자 데이터 아래의 `backup` 폴더를 사용합니다.
2. `리버리` 화면에서 백업할 종류와 검색·필터를 선택합니다.
3. `백업` 버튼을 누릅니다.
4. 현재 표시 항목 전체를 처리하려면 `복사`를 선택합니다. 일부만 고르려면 `선택`으로 카드를 고른 뒤 `선택 완료 → 복사`를 선택합니다.

복원하기:

1. 게임 저장 폴더를 선택하고 `전체 새로고침`을 수행합니다.
2. `백업` 화면에서 복원할 항목을 표시합니다.
3. `복원` 버튼 또는 카드의 복원 동작을 사용합니다.
4. `복사`를 선택하면 백업 원본을 유지하면서 게임으로 복원합니다. 저장 구조나 대상 파일 검증에 실패하면 복원이 중단됩니다.

별도 폴더로 내보내기:

1. 리버리의 `백업` 또는 백업 목록의 `복원` 선택 창을 엽니다.
2. 작업을 `내보내기`로 바꾸고 `복사` 또는 원하는 항목 선택을 진행합니다.
3. 내보낼 폴더를 선택합니다.
4. 필요하면 차량명을 파일 이름으로 한 빈 TXT 파일을 각 리버리 폴더에 함께 만듭니다.

`복사`는 원본을 유지합니다. `잘라내기`는 복사·검증 뒤 원본을 삭제하며, 기본 설정에서는 금지되어 있습니다. 일반 리버리의 게임 원본 삭제는 저장 구조와 내용 검증을 통과한 경우에만 가능하며, 잠긴 원본은 유지됩니다.

<details>
<summary>백업의 사용자 정보·외부 가져오기·자동 백업</summary>

- v1.5.3에서 생성하는 백업에는 백업 시점의 메모·○·△·×·숨김·잠금 정보를 함께 저장합니다.
- 백업 카드에서 저장된 사용자 정보를 읽을 수 있습니다. 이후 앱에서 바꾼 정보가 과거 백업에 자동 동기화되지는 않습니다.
- 복원 시 사용자 정보가 없는 항목은 백업의 정보를 채울 수 있습니다. 이미 저장된 사용자 정보는 유지합니다.
- 이전 버전의 백업에는 사용자 정보가 없을 수 있습니다.
- 별도 폴더 `내보내기`는 원본 리버리 폴더를 복사하는 기능입니다. 백업 저장소 인덱스의 사용자 정보까지 함께 내보내지는 않습니다.
- 백업 저장소를 다른 곳에 보관할 때는 리버리 폴더뿐 아니라 인덱스를 포함한 저장소 전체를 함께 복사하세요.
- `외부에서 가져오기`는 다른 위치의 `Livery`·`SoulBoundLivery` 폴더를 찾아 현재 백업 저장소로 정리합니다. 가져올 폴더에는 `header`와 `C_livery`가 필요합니다. 외부 원본은 유지합니다.
- `설정 → 자동 백업`으로 자동 처리를 켤 수 있습니다. 중복 처리 조건은 같은 설정 창에서 조정합니다.
- 백업 화면에서 일반·경매장 종류, 게임만·백업만·게임+백업 위치, 검색·정렬·묶기로 찾을 수 있습니다.
- 백업 카드의 `백업 삭제`는 백업 저장소의 항목을 삭제하며 게임 원본은 유지합니다. 잠긴 백업은 삭제를 제한합니다.

</details>

### 최근 변경사항과 적용 상태 확인

`리버리 변경 자동 감지`를 켜면 추가·제거·중복 변화를 확인할 수 있습니다. 최근 변경사항에서는 추가된 항목과 제거된 항목 등을 카드로 비교합니다. 현재 목록을 다시 읽으려면 `전체 새로고침`을 사용하세요.

게임에서 현재 적용한 리버리를 확인하려면:

1. FH6를 실행합니다.
2. Assistant의 `메모리 스캔` 화면을 엽니다.
3. `메모리 다시 스캔`을 누릅니다.
4. 결과와 이전 상태의 `신규 적용 / 적용 해제 / 변경 없음`을 비교합니다.
5. 결과를 Assistant 목록에 반영하려면 `적용`을 선택합니다.

이때의 `적용`은 스캔 결과를 Assistant에 반영하는 동작입니다. 게임의 리버리를 바꾸지는 않습니다. `재검토 필요` 항목이나 판정 실패 시에는 결과를 확정하지 않으며, 마지막 정상 적용 결과를 유지합니다.

### 게임에서 리버리 위치로 이동

1. 게임에서 `집 → 자동차 → 디자인 및 도색 → 내 디자인`을 엽니다.
2. 목록의 첫 번째 항목을 기준으로 준비합니다.
3. Assistant에서 해당 리버리 카드의 이동 버튼을 누릅니다.
4. `삭제 위치로 이동` 또는 `적용 위치로 이동`을 선택합니다.

대기 시간·방향키 간격·FH6 창 자동 활성화를 조정할 수 있습니다. 이동은 방향키 입력으로 대상 위치 선택을 보조합니다. 실제 삭제·리버리 적용은 게임에서 사용자가 수행합니다.

숨긴 항목은 이동 대상에서 제외되고, 잠긴 리버리는 이동을 제한합니다. 목록이 변경되면 새로고침하고, 게임의 실제 선택 위치를 확인하세요. 새로고침·대상 변경·게임 창의 포커스 변경 시 예약이나 남은 입력이 취소될 수 있습니다.

### 차량명과 제작자 이름 관리

차량 데이터베이스:

- `대시보드`에서 데이터 출처 선택·업데이트·출처 페이지 확인을 할 수 있습니다.
- HDR 또는 Datamining00 데이터를 사용하고, 사용자 차량명을 직접 저장할 수 있습니다. 직접 지정한 이름이 우선합니다.
- Datamining00의 새 데이터 알림에서는 업데이트하거나 `이 버전 건너뛰기`를 선택할 수 있습니다.
- 획득처·DLC는 제공되는 Datamining00 데이터에서 확인합니다.

제작자 이름 관리:

- 관찰한 제작자 코드와 이름을 기준으로 이전·현재 이름을 연결합니다.
- `이름 연결`과 `연결 해제`로 수동 조정할 수 있습니다.
- `통합 내역`과 리버리 수를 확인하고, `리버리 확인`으로 해당 제작자의 게임 리버리 목록을 열 수 있습니다.
- 열린 목록에서 `제작자 필터 해제`로 돌아갈 수 있습니다.
- `이름 재연결`은 해제했던 코드도 포함하여 관찰한 기록을 다시 연결합니다.
- `이름 연결 초기화`는 수동 이름 연결을 초기화하며, 코드별 연결 해제는 유지합니다.

이름 관리와 사용자 차량명은 앱의 표시·검색·집계에 사용됩니다. FH6 원본 파일의 제작자나 차량 정보를 변경하지 않습니다.

### 게임 내 썸네일 표시

`설정`의 두 항목을 각각 선택할 수 있습니다.

- `게임 내 썸네일에 경매장 표시`: 썸네일에 `Auction` 표시.
- `게임 내 썸네일에 잠금 표시`: 잠금 아이콘 표시.

정확히 연결된 썸네일만 처리하고 원본을 보관합니다. 옵션을 끄면 해당 표시를 원복합니다. 게임이 이미지를 교체한 경우 원본 보호 때문에 처리를 보류할 수 있습니다. 다시 표시하려면 `재적용`을 사용하세요. 성공한 항목은 교체된 이미지를 새 원본으로 보관합니다.

오류 알림은 표시·복원 오류, 교체 파일 보호 안내, 재적용 실패를 나누어 켜고 끌 수 있습니다. 오류 창의 `다시 보지 않기`도 사용할 수 있습니다. 알림을 꺼도 표시 작업과 원본 보호는 계속됩니다.

### 언어·화면·진단

- 한국어·English를 지원합니다. 왼쪽 아래에서 언어를 바꾼 뒤 프로그램을 다시 시작하면 적용됩니다.
- `항상 위에 표시`로 게임과 함께 사용할 때 Assistant 창을 유지할 수 있습니다.
- 창 크기에 맞춰 카드 목록이 배치되며, 카드의 제목·출처 정보를 펼치거나 접을 수 있습니다.
- 중복 실행을 제한합니다. 이미 실행 중이라는 안내가 나오면 열린 창을 사용하세요.
- `성능 측정`에서 실행 중 기록을 켜거나 끄고 결과 복사·로그 폴더 열기·기록 초기화를 할 수 있습니다. 초기 실행 시간은 항상 기록합니다.
- `진단 내보내기`로 상태 요약과 진단·성능 로그를 ZIP으로 저장할 수 있습니다. 원본 세이브·리버리 파일은 포함하지 않습니다.
- `설정 → 오픈소스 및 라이선스`에서 외부 구성요소의 고지와 소스·라이브러리 교체 안내를 확인할 수 있습니다.

## 문제 해결

| 상황 | 먼저 확인할 것 |
|---|---|
| 리버리·튜닝이 나오지 않음 | 실제 세이브 폴더와 `ContainersRoot` 구조, `전체 새로고침`, 목록 로딩 설정 |
| 일부 항목이 안 보임 | 일반·경매장 종류, 적용 상태, 검색, 분류·숨김·제작자 필터 |
| 튜닝만 안 보임 | `튜닝 불러오지 않기` 설정과 숨김 튜닝 필터 |
| 경매장 썸네일이 안 보임 | `CacheThumbnails`와 `.manifest`, 캐시 자동 감지 후 새로고침 |
| 적용 상태가 오래된 것 같음 | FH6 실행 후 메모리 다시 스캔하고 결과를 목록에 적용 |
| 메모리 스캔이 실패함 | FH6 실행 여부와 판정 상태·오류 내용을 확인. 마지막 정상 결과는 유지 |
| 3D 미리보기가 실패함 | 게임 차량 자산을 읽을 수 있는지, 도구·데이터 준비 및 OpenGL 환경 확인 |
| 3D 처리 중 메모리가 부족함 | 렌더링 배율과 텍스처 변환 동시 작업 수를 낮춰 다시 시도 |
| 썸네일 표시가 사라짐 | 경매장·잠금 표시 설정과 교체 파일 보호 안내를 확인하고 `재적용` |
| 복원이 중단됨 | 먼저 게임 세이브 새로고침. 백업 원본·저장 구조·대상 충돌 오류 확인 |
| 잘라내기가 선택되지 않음 | 잘라내기 금지 설정, 잠금, 원본 종류·검증 조건 확인 |
| 메모·설정 저장이 실패함 | 저장 실패 안내의 재시도 또는 취소 선택. 파일을 읽지 못했다면 기존 정보를 확인한 뒤 저장 |

[문제 제보](https://github.com/Datamining00/FH6_Garage_Analyzer/issues) 시 앱 하단의 버전·빌드 ID, 수행한 작업과 오류 내용, 필요하면 진단 ZIP을 함께 확인해 주세요.

## 데이터와 백업

일반판과 포터블은 다음 위치에 앱 사용자 데이터를 저장합니다.

```text
%LOCALAPPDATA%\FH6GarageAnalyzer
```

| 파일·폴더 | 저장 내용 |
|---|---|
| `annotations.json` | 리버리·튜닝 메모와 ○·△·× 분류 |
| `ui_preferences.json` | 숨김·잠금 등 앱 표시·편집 상태 |
| `app_options.json` | 설정 옵션 |
| `creator_aliases.json` | 제작자 이름 연결 기록 |
| `car_overrides.json` | 사용자 차량명 |
| `backup` | 별도 경로를 지정하지 않았을 때의 백업 저장소 |
| `thumbnail_originals` | 썸네일 원본과 원복 기록 |
| `preview3d_runtime` | 미리보기 도구·의존성·생성 데이터 |

앱 사용자 데이터를 보관하려면 프로그램을 종료한 뒤 폴더 전체를 복사하세요. 백업 저장소를 다른 경로로 지정했다면 그 저장소도 별도로 보관해야 합니다. 다른 PC에서는 세이브·캐시·백업 경로를 다시 확인하세요.

썸네일 원복이 필요하다면 `thumbnail_originals`를 함께 유지하세요. 일반판이나 포터블 파일을 교체해도 이 사용자 데이터 위치는 계속 사용합니다.
