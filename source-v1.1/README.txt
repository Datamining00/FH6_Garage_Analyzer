FH6 Assistant v1.1
================================

실행 방법
---------
1. 이 압축 파일을 쓰기 가능한 일반 폴더에 완전히 풉니다.
2. FH6 Assistant.vbs를 실행합니다.
3. 최초 실행에서는 Python 환경과 필수 패키지 준비로 시간이 걸릴 수 있습니다.

오류 확인
---------
- 프로그램이 열리지 않으면 run.bat을 실행하십시오.
- run.bat은 오류 내용을 CMD 창과 로그로 확인하기 위한 진단용 실행 파일입니다.
- 정상 사용 시에는 FH6 Assistant.vbs만 실행하면 됩니다.

주의 사항
---------
- 압축 파일 내부에서 직접 실행하지 마십시오.
- app.py, run.bat, setup_and_run.ps1, requirements.txt, data 및 fh6garage 폴더를
  서로 분리하거나 삭제하지 마십시오.
- 프로그램 사용 중 만들어지는 설정과 메모는 사용자 LocalAppData에 저장됩니다.
- 인게임 이동 기능을 사용할 때는 FH6 화면과 현재 정렬 상태를 먼저 확인하십시오.
